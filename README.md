# 🧮 Arithmetic Grid Game

An interactive, browser-based math puzzle game built using **HTML5** and **CSS3**. The game features a $4 \times 4$ interactive grid with blocked obstacles, small corner position indicators, and customizable number and operation tiles with smooth visual animations.

---

## ✨ Features

* **4×4 Interactive Game Grid**: Features playable cells alongside striped obstacle blocks (`.blocked`).
* **Numbered Tile Containers**: Clean card layout displaying 14 selectable number tiles and 4 arithmetic operation tiles ($+$, $\mathbf{-}$, $\mathbf{\times}$, $\div$).
* **Corner Position Labels**: Small position numbers situated in the top-left corner of individual grid cells.
* **Hover & Interactive Feedback**: Smooth CSS scale transforms and color highlights when hovering over playable cells and tiles.
* **Dynamic Ambient Background**: Animated linear gradient shift and floating blurred particles for an enhanced UI experience.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic web structure and layout wrappers.
* **CSS3**: Flexbox, CSS Grid layout, keyframe animations, and backdrop filters.
